悟空游中国 · MC 轻量版（2026-11-02）

本目录是独立轻量副本；原 wukong-china 项目、FBX/MAX 和高清贴图没有修改。
启动：安装 Node.js 22 后双击 start-heritage.cmd；地址 http://127.0.0.1:5177/。
首页 index.html 为访古游戏；heritage.html 转到首页。当前工程仅保留悟空访古内容。
操作：WASD / 方向键移动，Shift 奔跑，拖动旋转，滚轮缩放，C 切换全景，M 打开地图。
手机使用方向键。三处通用示范场景可在金色圆环打卡；模型库场景供绕行观察，暂不支持室内行走。

地图直接使用用户提供的 地图.png，设置 8 个可点击标签和地点标记；保留全部 23 处资料搜索。
镜湖小庙按用户 MC 参考图重新搭建，含灰瓦、翘檐、红墙、圆窗、木门、台阶和石狮。
其余 39 项由已转换的 GLB 表面体素化、共享配色和合并面处理，没有携带原高清贴图。
模型库共 40 项（包括建筑、部件及雪僵尸），并非 40 座现实建筑。缩略图为本版模型渲染。
主角增加头发层次、五官、服饰缝线、护甲铆钉、手指及边缘倒角；保留 Walk 动画。
40 项模型约 20.1 MB、314348 三角面；主角 512916 字节、8316 三角面。

地点对应仍是候选或主题配置，不能据此认定为真实古建扫描件。

应县木塔入口使用保留的通用三层方塔示范，并非真实八角木塔复原。

部署：使用 zhihu-ai-works-deploy-helper 生成的根目录 ZIP 上传知乎 AI Works。
项目是纯静态 Three.js/Vite 前端；npm ci 安装、npm run build:track 远端构建，输出 dist。
构建配置 vite.config.js 将输出固定为 dist，并构建访古首页和兼容旧入口。
Node 版本通过 package.json engines 固定为 22.x；没有后端或端口改写。
使用 Skill 的知乎事件桥；构建票据由部署平台提供，不需手工填写。
没有创建或修改 CloudBase 云资源。50 MB 容量按压缩包及 dist 未压缩合计分别检查，目标 45 MB 以下。

限制：40 项模型来自用户提供的模型文件夹，未破解或解密 PAK。轻量化会损失原模型细部。

2026-11-02 gamedev 技能优化（第二轮）
使用 router / threejs-scene-setup / threejs-materials-lighting / camera-systems / level-design / performance-optimization；保留 three 0.170.0。
1. 将配景减面与配色转换移至 scripts/bake-courtyard.mjs，浏览器只加载 public/models/courtyard-lite.glb。修改素材或布局后执行 npm run assets:bake，再执行 npm run build。
2. 本机 Node 实测：原文件读取+解析+转换 542 ms；烘焙文件读取+解析 5 次中位数 8.15 ms。配景传输体积 2,698,692 → 1,063,476 字节，减少 60.6%。这些不是手机帧率或公网下载速度数据。
3. 增加 camera-rig.js：跟随平滑、前视偏移、建筑包围盒遮挡收近与平滑恢复；不改变玩家原本的环绕缩放距离。镜头碰撞使用保守包围盒，屋檐外侧可能提前收近。
4. 中轴铺装、侧院草地、块状远山形成空间分区；保留原角色尺度及斜握金箍棒。
5. 根据实际位移播放行走动画，撞墙时停止踏步；停步后继续短暂刷新阴影。HUD 文本仅状态变化时更新；QA 面板降到每秒两次刷新。
