# 悟空游中国 · 山河访古

基于 Three.js / WebGL 的 MC 风格古建探索游戏。当前工程只包含悟空访古；校园入口、源码、模型包与校园专用工具已移除。

## 启动与构建

安装 Node.js 22，双击 `start-heritage.cmd`，或运行：

```sh
npm ci
npm run dev
```

打开 http://127.0.0.1:5177/ 。`start.bat` 也可启动并打开同一项目。

```sh
npm run build
npm run preview
```

`dist/` 是可部署的静态站点。`index.html` 为首页，`heritage.html` 为兼容跳转入口。生产环境需要 HTTP 服务。

## Cloudflare Workers 部署

本项目通过 Workers Static Assets 提供服务，自定义域名为 `wukongtour.chipai.cc`。

```sh
npm ci
npm run build
npx wrangler login
npx wrangler deploy
```

`wrangler.jsonc` 包含静态文件目录和域名配置；部署账户须有 `chipai.cc` 的管理权限。若在 Cloudflare 控制台连接 GitHub 自动构建，构建命令使用 `npm run build`，部署命令使用 `npx wrangler deploy`，仓库根目录为项目根目录。

## 知乎建筑回答快照

建筑知识面板读取 `public/knowledge/zhihu.json`。使用已完成授权的知乎官方 CLI 更新：

```sh
node scripts/update-zhihu-knowledge.mjs --cli "<官方 setup 返回的 binary_path 绝对路径>"
```

可追加 `--site shisi` 只更新单个场景并保留其余数据。支持 `shisi`、`yungang`、`xuankong`、`yingxian`、`dule`、`foguang`、`xiaoxitian`、`shuilu`、`kaiyuan`。每处进行一次搜索（最多 10 项），过滤回答、去重后按返回的赞同数取最多 3 条，保留作者、短摘要、原文链接与抓取时间。这是检索结果中的高赞回答快照，不代表全站最高赞，也不实时刷新。无有效回答时显示空状态，不生成替代回答。

查询失败不会覆盖已发布快照。Access Secret 由本机官方 CLI 管理，不写入 JSON、Git 仓库或浏览器资源。更新后执行 `npm run build` 和 `npx wrangler deploy` 发布。

## 主要功能

- 古建群漫游：参考小雷音寺地图构建十三座建筑、三层院落与十六处行走地标；支持侧门进出、台阶登高、全景、单体观察和手动揭开屋顶。模型为原创概括，不是游戏资产提取或精确测绘。
- 九条主题路线：时思寺、云冈石窟、悬空寺、应县木塔、独乐寺、佛光寺、小西天、水陆庵、开元寺东西塔；共二十七处观察点，对照建筑图片答题并收集游记。
- 悬空寺筋斗云：升降、加速、绕山观景与安全落地；实体岩壁、屋顶和楼阁参与碰撞。
- 访古地图：九处艺术地图标记全部可玩，另保留二十三处古建资料检索；当前场景另有实时定位小地图。
- 四十项古建与构件模型：搜索、筛选、加载查看、下载 GLB；支持导入本地内嵌资源 GLB。
- 三处通用示范场景打卡、PNG 留影、浏览器进度保存与手机透明摇杆。

主角直接加载 `public/models/wukong-current-hero.glb`，使用文件内的 `Idle`、`Walk`、`Run` 动画，并在停止、行走与奔跑之间平滑切换。游戏统一按 1.8 米角色高度处理台阶、视角和乘云；模型的顶点色、金箍棒与关节层级保留。`src/heritage/hero.js` 是早期程序建模源，当前网页使用 GLB 资产。

## 古建群 GLB 与独立技能

在古建群的“查看设置”中点击“导出古建群 GLB”，可保存包含牌匾、材质、门洞碰撞、台阶和导览点的单文件模型。导出保留完整屋顶，排除运行时指引与悬浮标签。“导入建筑 GLB”会识别 `extras.heritageScene` 的群落并进入漫游；普通 GLB 仍进入单体预览。导入群落后，可在设置中返回内置古建群。

“导入建筑 GLB”现在先打开导入指南，提供技能介绍与安装包、可复制的调用示例、三步导入说明，以及普通模型和可漫游群落的接口区别。页面可下载[完整接口说明](public/downloads/heritage-glb-interface.md)和[三建筑布局参数](public/downloads/heritage-layout-example.json)。选择文件按钮始终保留在底部；取消文件选择可继续阅读，导入失败会在页内显示原因并允许重试。手机端从游玩菜单进入同一说明页。

独立技能位于 [`skills/image-to-heritage-glb`](skills/image-to-heritage-glb/SKILL.md)，包含原创建筑群参考 GLB、三建筑与十三建筑参数模板、无 npm 依赖的 Node.js 建模/校验脚本和独立预览器。将整个文件夹复制到个人 skills 目录即可使用；技能不读取本项目源码，也不依赖本项目安装。发行 ZIP 为 [`public/downloads/image-to-heritage-glb.zip`](public/downloads/image-to-heritage-glb.zip)。

技能在写入 GLB 前检查完整通行矩形边界、节点归属、站位和路径连通性，拒绝“站位在边界内、整块地面却越界”的输出。生成或校验失败会写入 `ok:false` 的报告，保留已有模型；成功报告分别列出结构、契约、参考控制器路径检查，官方规范与实际目视检查需另行完成。`npm run test:skill-output` 对照实际网页导入器验证越界、断路、节点关系和失败重试行为。

```text
使用 $image-to-heritage-glb，根据这张古建筑图片生成可导入 GLB，保留门洞与台阶，输出模型、参数和校验报告。
```

图片由 agent 分析后转成布局参数；单张图不可见的尺寸、背面和结构需要合理补全。它不是自动摄影测量，也不包含游戏官方模型。详见 [本次重建与导出说明](docs/ancient-compound-glb.md)。

## 操作

打开或刷新网页时默认显示中国漫游地图。点击建筑地名选择目的地，再点“出发”进入对应路线；已有游记进度继续保留。

手机端默认收起路线说明与建筑设置，点右上角“菜单”展开；左下方透明摇杆支持 360° 移动，轻推慢走、推满正常行走，松手回中停止。观察与场景地图保留在右下方。横屏同样使用紧凑布局；打开弹窗、切换场景、横竖屏切换或切到后台都会清除摇杆输入。乘云时摇杆控制水平移动，右侧按钮控制升降。

九条路线靠近主建筑入口后会自动开门并显示知乎回答摘要。可进入的五座主殿使用实体门扇动画，石窟、悬空寺及实体塔模型使用导览门扉过场；原有通行范围不变。每次进入路线仅自动弹出一次，关闭后可在门前点“重看”或按 E 查看。

开门后的面板可点“拍建筑纪念照”；“更多”或手机菜单内也可直接打开当前路线的“建筑写实纪念照”。九处建筑各有一张独立生成的 1672×941 写实画面，呈现黑神话氛围，并可保存 PNG 原图。图片按需加载，不占用初始场景的下载带宽。它们是预制 AI 场景演绎，非实时模型生成、游戏截图或文物测绘复原；完整提示词见 `docs/architecture-photo-prompts.json`。原“留影”仍保存当前 3D 视角。

| 操作 | 功能 |

| WASD / 方向键、Shift | 行走、奔跑（乘云时加速） |

| V | 古建群单体细看 |

开元寺的「寺门望双塔」由原 4 号改为 1 号。寺门现位于南侧入口，1 号圆环随寺门移动；东西塔及 2、3 号位置保持不变，两塔之间可直接横向通行。三处打卡图均为独立 AI 图片，不再使用地图占位。

原四景的七张拼图通过 `reference-crops.js` 中的像素窗口仅显示游戏部分，排除手机界面、现实照片和拼图标语；源图片保留以便调整取景。全旅程共二十七处，继续使用同一浏览器存档键。存档内容升级为版本 2：旧 `kaiyuan-4` 记录转为新 `kaiyuan-1`；已删除的旧 `kaiyuan-1` 不会误算作寺门记录，其余记录保留。读取时不覆盖原存档，在正常保存时写入新版本。

## 建筑通行与遮挡

古建群三座殿堂和听松塔新增左右侧门、对应石阶；时思寺、独乐寺、佛光寺、小西天、水陆庵的主题主殿可从正面和左右侧面进入。台阶和地板使用真实高度，墙、柱、栏杆与造像保留碰撞。路线光点按可行走楼面寻路。

漫游时屋顶始终保留。建筑挡住悟空时，只对人物附近、位于镜头与人物之间的部分渐隐；离开遮挡区域恢复原样，屋顶轮廓和建筑阴影不变。镜头保持旋转距离，不再因墙体遮挡突然贴近或隐藏人物。全景和单体细看显示完整建筑，手动揭顶仍只在单体观察中生效。

未制作室内的实心塔体、山岩，以及导入模型继续保留实体碰撞。

## 悬空寺场景更新（2026-11-04）

参考地图中的岩壁环抱形态，重做前部岩肩、内凹岩龛、悬挑岩层、侵蚀沟槽和高低错落的后方山脊；增加岩台草色、松树、灌木和山脚覆草岩块。山体前后均有实体厚度，飞行碰撞与体素占据区域共用生成数据。步行观察点保持可达，飞行范围扩大以支持绕到山背。

全景按屏幕宽高取景，远景雾随距离调整；天空跟随镜头，避免远处出现球体裁切边。悬空寺隐藏旧场景的方块云，突出山体轮廓。场景几何为 48,906 三角面、4 个合批（不含主角、环境与任务标记）。
